Python

Python is a programming language known for its clear syntax and readability, making it ideal for beginners and powerful for full-stack, data, and AI development.

Python's basics

Variables and data types

In Python, you don't need to declare data types explicitly. You simply assign a value to a name using the equal sign (=) (example: name = "Luke")

There are 4 data types in Python.

  1. Text data type (which is called "string" and is enclosed in double quotes ("), for example: name = "Alice");
  2. Whole numbers data type (which is called "integer", for example: number = 52);
  3. Decimal numbers data type (which is called "float" and has a dot (.) instead of a comma (,), for example: number = 4.73);
  4. Boolean data type (which can be True or False, for example: is_alive = True).

Outputting data (print)

The print() function displays text or variable values on the screen (for example: print("Hello!"))

Arithmetic operators

Arithmetic operators are used to perform standard mathematical calculations (for example: print(5 + 10)).
There are also special arithmetic operators, like floor division (//), which is like a normal division but without the decimals, and modulo (%), which is the remainder
of the division of the numbers.
